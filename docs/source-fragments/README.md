# Source Fragments

이 폴더는 "완전한 클래스가 아니어서 `.java`로 만들지 않은 부분 소스"를 기록하기 위한 폴더입니다.

## 현재 상태: 해당 없음 (Android)
최종보고서 ver1.5.0 + Android 담당 팀원 개인보고서를 전수 조사한 결과, 텍스트로 발견된 Android 코드는 **`MainActivity`, `MainActivity01` 2개뿐이며 둘 다 package~닫는 중괄호까지 완전한 클래스**였습니다. 그 외 활동(층별 병실 화면 등)에 대한 코드 텍스트는 전혀 발견되지 않았고(설명/스크린샷만 존재), "일부만 있는 코드 조각" 자체가 없어 이 폴더에는 현재 아무 파일도 없습니다. 완전한 두 클래스는 `mobile-app/recovered-source/`에 있습니다.

## WPF 관련 부분 증거
WPF(MainWindow/Window2)는 클래스명·메서드명·역할 설명 등 "부분 증거"가 있지만, 사용자 지시에 따라 이 폴더가 아니라 `../../desktop-app/README.md`에 기능 명세 형태로 정리했습니다(코드 조각이 아니라 스펙 문서이므로).

## 향후
다음 단계에서 하드웨어 담당 팀원 개인보고서 등을 더 정밀하게 재조사할 경우, 진짜 "일부만 있는 코드 조각"이 발견되면 이 폴더에 근거와 함께 `[부분 소스]`로 추가할 수 있습니다.
