# Missing Source

다음 단계(재구성)에서 다루어야 할, 현재 원본 텍스트가 없는 파일 목록입니다. 이번 2단계에서는 이 파일들을 **생성하지 않았습니다.**

> **3단계 갱신 안내**: 아래 목록 중 대부분은 3단계에서 `mobile-app/reconstructed-app/`, `desktop-app/reimplemented-wpf/`에 **[신규 재구성]/[신규 재구현]**으로 실제 작성되었습니다. 이 문서는 "당시 원본이 없었다"는 2단계 시점의 분석 기록을 그대로 보존하기 위해 수정하지 않았고, 각 항목이 어떤 파일로 재구성되었는지는 `docs/source-map.md`의 "3단계 신규 추가분" 표와 `docs/reconstruction-changes.md`를 참조하십시오. **유일하게 계속 미해결로 남은 항목은 "추가 Activity (2층~6층 병실 화면)"입니다** — 근거가 없어 3단계에서도 생성하지 않았습니다.

- 원본 존재 여부: 없음
- 근거: 최종보고서·개인보고서 어디에도 텍스트/설명 없음(존재 자체가 언급되지 않음)
- 복원 가능성: 불가(근거 없음)
- 신규 작성 필요 여부: 필요(재구성 단계에서 처음부터 작성해야 함, 이번 단계 범위 아님)

- 근거: 최종보고서에 파일명("메인화면 레이아웃(activity_main.xml)")과 화면 스크린샷만 존재, `R.id.button2` 등 일부 리소스 ID는 `MainActivity.java` 코드에서 간접 확인 가능
- 화면/기능 설명: 층별 버튼 6개(1~6층), ConstraintLayout, CardView(층별 버튼 배경), TextView("건양대학병원", "4조"), ImageView(로고)
